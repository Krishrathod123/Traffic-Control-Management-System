# Traffic Control Management System

## Technology
- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Database: SQLite

## Run
1. Install Python 3.
2. Open terminal in this folder.
3. Run: `pip install -r requirements.txt`
4. Run: `python app.py`
5. Open: `http://127.0.0.1:5000`

The SQLite database `traffic.db` is created automatically on first run.

## Main features
- Traffic signal dashboard
- Signal status control
- Vehicle count
- Incident reporting
- Traffic violation management
- SQLite database
- REST-style backend APIs
- Responsive UI
